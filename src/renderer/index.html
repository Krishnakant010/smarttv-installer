About & Credits

SmartTV Sideload Installer is a generic open-source utility for installing and sideloading applications onto Samsung Smart TVs (Tizen OS) and LG Smart TVs (webOS).

Upstream Attribution & Credits

  • NuvioMedia (NuvioTVSmart-Installer): Original upstream installer application architecture, LG device management, and Samsung certificate persistence.
  • Reis Can (reisxd) (tizen.js, TizenBrew): Pure Node.js Samsung Developer OAuth certificate generation and ADB sync sideload transport.
  • LG webOS OSE Team (@webos-tools/cli): Official webOS development and packaging CLI tools.
  • webOSBrew Team (webOS Homebrew Channel): Open-source homebrew ecosystem and package repository for LG webOS.
  • iqui27 (nuvio-native-legacy): High-performance native C / SDL2 / WASM TV client.
  • Krishnakant Gangurde: Generic fork, universal package inspection (WGT/IPK), custom repository release fetcher, and de-coupled sideloading engine.
